# BUN BUN BURGER

「腹いっぱいって、しあわせだ。」をコンセプトにした、大阪の架空のクラフトバーガーショップのポートフォリオサイトです。

FAST FOOD GRAPHICS × JAPANESE STREET を軸に、ポスター、メニューボード、包装紙、ステッカーなど実店舗のグラフィックをウェブUIへ落とし込みました。スクロールに合わせて材料が重なる BUILD YOUR BURGER、商品切替、マルキー、ステッカー、ポラロイド風スナップなどを実装しています。

## Pages

- HOME — ブランド体験と店舗情報を集約
- MENU — バーガーラインナップ
- ABOUT — 素材と作り方へのこだわり
- SHOP — 店舗イメージとアクセス

## Image policy

サイト内の写真3点（バーガー、店内と人物、テイクアウトパッケージ）は OpenAI ImageGen で本作品のために生成したオリジナル素材です。第三者のロゴやウォーターマークは含みません。配信用には WebP へ変換し、表示領域に応じて遅延読み込みを行っています。

## Notice

BUN BUN BURGER はポートフォリオ制作のための架空ブランドです。店舗名、住所、価格、営業時間などはすべて架空の情報です。
